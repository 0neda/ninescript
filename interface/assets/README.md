# Imagem de fundo do console do Ninescript

`topo.png` é a imagem original fornecida para o projeto, baixada de:

https://play-lh.googleusercontent.com/DbZwJDCp2G6qRbcKJxTptlp25a9V1kVA9RvcLME_Itn8GJDx3oBGrtFCX5kHZBlH62k2ES_hbdC1MLO9NQs1dA

A IDE ajusta a exibição proporcionalmente ao console e compõe a imagem com
50% de opacidade sobre o fundo escuro. O texto aparece em primeiro plano.
O arquivo original (512 × 512 pixels) é preservado no projeto.
